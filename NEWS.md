# selectools 0.3.0 - 2026-05-25

## Added
### Model selection pipeline
A whole pipeline for model selection procedures on different trajectories has been implemented.
This major addition includes the following functions:

  - `trajectory_formulas()`: simply input a two-sided formula with or without random structures, 
  define the trait on which different trajectories will be applied, potential interacting variables 
  and trajectories to implement (constant, linear, quadratic, factor and different threshold trajectory shapes).
  See `?trajectory_formulas` for details. Returns a `trajectory.formulas` object with 
  constructed formulas for each trajectory.

  - `estimate_threshold()`: providing threshold formulas or a `trajectory.formulas` object,
  the function estimates the best threshold point for each threshold shape based on AICc or AIC.
  See `?estimate_threshold` for details. Returns a `threshold.estimation` object.

  - `fit_models()`: takes formulas (or `trajectory.formulas` objects) and threshold points 
  (or `threshold.estimation` objects) as inputs and returns model fits for all trajectories
  (threshold and non-threshold ones). See `?fit_models` for details. Returns a `models` object.

  - `dredge_trajectories()`: applies dredge method selection based on AICc or AIC with the 
  `MuMIn::dredge()` on `models` objects. See `?dredge_trajectories` for details. 
  Returns a `dredge.results` object.

  - `best_trajectory()`: selects the best trajectory based on `dredge.results` objects generated by
  `dredge_trajectories()`. See `?best_trajectory` for details. Returns a `best.trajectory` object.

  - `select_trajectory()`: a complete pipeline. This function is a wrapper which 
  aggregates all previous functions to automatically transform a single formula 
  into different fitted model trajectories, and selects the best one based on AICc or AIC.
  See `?select_trajectory` for details. Returns a `best.trajectory` object.

All functions come with their `S3` methods. See help page and README for details.

### Layout helpers
Small helpers for layout (separation lines, title boxes, first letter in uppercase).

## Changed
### dredge_pglmm and internal functions
- We added a print S3 method to `dredge_pglmm()` instead of the function printing the results instantly.
Simply run the object storing `dredge_pglmm()` results to display a readable summary and dredge table.

- Argument `formulaRE` now requires a formula object rather than a character string.
For example, instead of:
```r
res <- dredge_pglmm(
  formulaRE = "log_onset ~ 1 + (1 | Species)", # character
  fixed = c("log_afr", "log_mass"),
  data = senescence,
  rank = "AICc",
  family = "gaussian",
  cov_ranef = list(Species = tree_ultra),
  estimate = TRUE,
  std.err = TRUE,
  round = 3)
```
you now have to use:
```r
res <- dredge_pglmm(
  formulaRE = log_onset ~ 1 + (1 | Species), # formula
  fixed = c("log_afr", "log_mass"),
  data = senescence,
  rank = "AICc",
  family = "gaussian",
  cov_ranef = list(Species = tree_ultra),
  estimate = TRUE,
  std.err = TRUE,
  round = 3)
```

- Within internal functions, each mention to df (degrees of freedom) has been renamed k (number of parameters)

Tests and codes have been adapted according to these changes but the functioning 
of `dredge_pglmm()` is otherwise strictly the same.
